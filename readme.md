# BPL Medical Tech Scraper - Medical Device Intelligence

A specialized data extraction engine designed to crawl, parse, and structure medical technology product specifications and images from industry-leading portals (BPL Medical Technologies).

## 🏥 Project Overview
The **BPL Medical Tech Scraper** is a high-precision utility built to transform unstructured web data into structured intelligence. It specifically targets medical device catalogs, extracting detailed technical specifications, product hierarchies, and high-resolution imagery. This tool is essential for market research, competitive analysis, and building comprehensive medical product databases.

## ✨ Key Features
- **Hierarchical Data Extraction**: Seamlessly parses parent product categories and their corresponding sub-products into structured JSON formats.
- **Automated Specification Mapping**: Extracts complex technical tables and formats them into usable data attributes.
- **Image Intelligence**: Automatically identifies and retrieves high-resolution product imagery for visual documentation.
- **Advanced Data Cleaning**: Built-in logic to filter noise, handle HTML artifacts, and ensure 100% data integrity.
- **Interactive Research Lab**: Provided as a Jupyter Notebook for real-time monitoring and iterative refinement of the scraping logic.

## 🛠️ Tech Stack
- **Analysis & Orchestration**: Python 3.10, Jupyter Notebook
- **Parsing Engine**: BeautifulSoup 4 (BS4), Selenium
- **Data Structuring**: Pandas, JSON
- **Network**: Requests
